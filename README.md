# مسجّل (Eb3atly-)

تطبيق تسجيل صوت بسيط بواجهة عربية (RTL)، بيشتغل على المتصفح وكمان كتطبيق أندرويد (APK) باستخدام Capacitor.

## المميزات

- تسجيل صوت مع إيقاف مؤقت وإلغاء، وعلامات (Markers) أثناء التسجيل وبعده.
- فولدرات لتنظيم التسجيلات (إعادة تسمية، نقل، حذف، والفولدر الأخير مش بيتحذف).
- مشغّل بسرعات مختلفة، وتكرار، وتثبيت الطبقة الصوتية، وقفز ±10 ثواني.
- **التخزين الدائم**: التسجيلات بتفضل محفوظة بعد إعادة تشغيل التطبيق (الميتاداتا في localStorage، والصوت في IndexedDB).
- **نسخ احتياطي** كملف ZIP، واستيراده بعدين. على الأندرويد النسخة بتتشارك عن طريق شاشة المشاركة (درايف، ملفات، إيميل...).
- بيشتغل أوفلاين، والخط Tajawal متضمن في التطبيق.

## التشغيل محلياً

المتطلبات: Node.js 22 أو أحدث.

```bash
npm ci
npm run dev        # يفتح نسخة الويب على http://localhost:5173
npm test           # اختبارات ZIP واختبار دخان للواجهة كاملة
npm run build      # يبني نسخة الويب في مجلد dist/
```

## بناء APK

### من GitHub Actions (الأسهل)

كل push على `main` وكل Pull Request بيشغّل workflow اسمه **Android APK** (`.github/workflows/android-apk.yml`):
يشغّل الاختبارات، يبني الـ APK، ويرفعه كـ artifact اسمه `recorder-debug-apk`.
من صفحة الـ run في تبويب Actions حمّل الملف وثبّته على موبايلك (لازم تفعّل "تثبيت من مصادر غير معروفة").

### محلياً (بيحتاج Android Studio و JDK 21)

```bash
npm run apk:debug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

لنشر التطبيق على Google Play لازم تبني نسخة `release` موقّعة (AAB) بمفتاح توقيع خاص بيك. ده لسه ما اتعملش.

## هيكل المشروع

| المسار | المحتوى |
|---|---|
| `index.html` | الواجهة (الـ markup) |
| `src/main.js` | المنطق الرئيسي: الشاشات، التسجيل، المشغّل، الفولدرات، الاستيراد والتصدير |
| `src/styles.css` | التنسيقات |
| `src/storage.js` | حفظ الميتاداتا (localStorage) والصوت (IndexedDB) |
| `src/zip.js` | كتابة وقراءة ملفات ZIP للنسخ الاحتياطية |
| `tests/` | اختبارات الوحدات (`zip.test.js`) واختبار الدخان للواجهة (`app.smoke.test.js`) |
| `android/` | مشروع الأندرويد (Capacitor). إذن الميكروفون متضاف في `AndroidManifest.xml` |
| `capacitor.config.json` | إعدادات Capacitor (appId: `com.eb3atly.recorder`) |

## التسجيل على الأندرويد

- على الموبايل التسجيل بيتعمل بالـ plugin `capacitor-voice-recorder` بصيغة M4A (AAC) بجودة ثابتة.
- على المتصفح التسجيل بيستخدم `MediaRecorder` بالصيغة اللي المتصفح بيدعمها، وفيه إعدادات جودة وتحسين صوت.

## قيود معروفة

- **التسجيل في الخلفية غير مدعوم حالياً.** لو قفلت الشاشة أو خرجت من التطبيق، التسجيل ممكن يقف. الحل الكامل يحتاج Foreground Service في كود أندرويد أصلي، وده خطوة قادمة.
- على الأندرويد مفيش عرض مباشر لمستوى الصوت (الـ plugin مش بيوفّره)، والموجة بتتحرك بشكل تجميلي.
- النسخ الاحتياطي بيتجمّع في الذاكرة قبل ما يتشارك، فالمكتبات الكبيرة جداً ممكن تحتاج ذاكرة كتير على موبايلات ضعيفة.
- مفيش تشفير للتسجيلات المحفوظة على الجهاز.
